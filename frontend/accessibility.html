Our commitment

We want every patient to be able to use this website comfortably. We aim to follow widely recognized accessibility guidelines (WCAG) and to keep improving.

What we've done

  • Clear, readable typography with adjustable zoom on all devices.
  • Keyboard navigation with visible focus indicators.
  • Descriptive text for images and meaningful link labels.
  • Respect for reduced-motion preferences.

Need help?

If you have trouble using any part of this site, or need information in another format, please call 310·467·0101 and we'll be glad to help.
