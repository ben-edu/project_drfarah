
# Dr. Farah Website Design Prototype — Version 2

## What changed from version 1

This refreshed prototype adds:

- richer contact presentation in the utility bar and contact section;
- favicon and logo mark;
- additional SVG visual assets to communicate service type and premium clinic positioning;
- SEO meta tags, Open Graph tags, and MedicalClinic structured data;
- temporary-environment noindex protection;
- cookie notice banner;
- a fuller set of appointment slot choices in booking step 2;
- a more content-complete staging-ready homepage.

## Notes

- This is still a static frontend prototype.
- Booking remains frontend-only and does not submit data anywhere.
- The phone number, email, and address used here are temporary prototype values and should be verified before final launch.
- The booking system should later use the existing Soria SMTP pattern for reservation notifications.
- The temporary domain should remain blocked from indexing until final-domain migration.
